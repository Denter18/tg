# NoDPI TG Bridge

Отдельное Android-приложение для обхода блокировки **Telegram по IP-адресам** (когда DPI-обход не помогает, потому что подсети 149.154.x.x / 91.108.x.x не маршрутизируются у провайдера, и веб-шлюзы `kwsN.web.telegram.org` тоже не открываются).

Трафик Telegram заворачивается в бинарные WebSocket-кадры и идёт на ваш Cloudflare Worker (IP Cloudflare провайдер не режет), а Worker пересылает кадры в веб-шлюз Telegram. Содержимое защищено шифрованием MTProto поверх всей этой обёртки.

## Состав

| Путь | Назначение | Куда переедет при слиянии |
|---|---|---|
| `worker/` | Cloudflare Worker (мост) | без изменений |
| `tgws_bridge.py` | адрес моста, пути `/dc/N[m]`, рукопожатие | без изменений |
| `tgws.py` | копия из основного приложения (AES/детект DC/PacketSplitter/WS) | уже там |
| `tunnel.py` | копия TUN-ретранслятора | уже там |
| `main.py` | движок моста + минимальный UI | движок — как фолбэк-транспорт |
| `java_src/` | VpnService, маршруты только TG-подсетей | маршруты не нужны (там 0.0.0.0/0) |
| `tests/` | юнит-тесты чистой логики | без изменений |

## Как пользоваться

1. **Развернуть Worker** (5 минут, инструкция в `worker/README.md`):
   `npm i -g wrangler && wrangler login && wrangler deploy` в папке `worker/`.
2. **Собрать APK**: создать репозиторий из этого каталога, запушить — GitHub Actions соберёт APK (см. ниже). Или `buildozer android debug` локально.
3. Установить APK, вписать адрес Worker'а в поле «Адрес моста», нажать «Запустить», разрешить VPN.
4. Открыть Telegram и проверить лог: `[Telegram] DC2 через мост ...`, статистика каждые 30 с.

## Сборка APK через GitHub Actions

Репозиторий уже содержит `.github/workflows/build_apk.yml` — на push в `main`/`master` (или вручную, Run workflow) собирается APK, он появляется в Artifacts. Версии подобраны вместе: p4a `v2024.01.21` = Python 3.11.5 + Kivy 2.3.0 + NDK 25b — их не стоит менять по отдельности.

## Проверка логики на ПК

```
python tests/test_tg_bridge.py     # или: python -m pytest tests/ -v
python -m py_compile main.py tgws_bridge.py tgws.py tunnel.py
```

Полный UI-запуск на ПК не поддерживается (нужен Android VpnService): на ПК приложение стартует, но VPN недоступен.

## Ограничения и заметки

- Бесплатного тарифа Cloudflare хватает с запасом (запросы = открытия соединений).
- Если Cloudflare окажется заблокирован: переносите мост на любой VPS — протокол простой (`/dc/N[m]`, бинарные кадры), см. `worker/README.md`.
- В VPN-режиме маршрутизируются **только** подсети Telegram: остальной трафик устройства не трогается.
- Слияние с основным приложением описано в `MERGE.md`.
